# Course requirements

CampusSwap is the course project for **UX/UI for Startups** (retake). The rubrics come from the [course page](https://ulmost.notion.site/SUM23-UX-UI-for-Startups-Course-6d1ae1f3cac94f09876ca07f8a1174f7).

## Retake rules

- All four projects must be ready for review: UX Research, Lo-Fi Prototype (midterm), Hi-Fi Prototype, Case Study.
- Everything is wrapped in **one Figma file**, plus an offline `.fig` copy.
- Expect **at least 2 theory questions** on the course material and how it relates to the project.
- The maximum grade for a retake is **B**.

## Exam format

| Part | Time |
|---|---|
| Presentation and prototype demo | 20–30 minutes |
| Figma file inspection and Q&A | 5–10 minutes |

Camera and screen share stay on. Keep your school ID ready.

## Assignment rubrics (summary)

=== "1 · UX Research"

    | Part | Points | Must include |
    |---|---|---|
    | A. Research plan | 35 | Background, goals, research questions, method, recruiting criteria; interview guide (intro, questions with rationale, wrap-up); survey (questions with rationale) |
    | B. Research report | 35 | Executive summary, background and goals, at least 2 key findings backed by data, recommendations, appendix with the affinity board |
    | C. Rough design | 30 | At least one screen with annotations, at least one design principle and one research finding applied, rationale paragraph |

=== "2 · Lo-Fi Prototype"

    | Part | Points | Must include |
    |---|---|---|
    | A.1 Interview notes | 10 | Notes per participant, one color each |
    | A.2 Themes and opportunities | 10 | Grouped notes with labels and HMW questions |
    | A.3 Feature ideation | 10 | At least 10 self-explanatory ideas |
    | A.4 Feature prioritization | 10 | Matrix or value vs complexity; selected features marked with research reasons |
    | B.1 User flow | 10 | Stages broken into tasks |
    | B.2 Paper sketches | 10 | Crazy 8s scans, each with a description |
    | B.3 Digital prototype | 40 | 4-screen lo-fi clickable wireframe, a note per screen, common UI patterns |

=== "3 · Hi-Fi Prototype"

    | Part | Points | Must include |
    |---|---|---|
    | A.1 Idea brief | 5 | One-liner and value proposition |
    | A.2 Usability study guide | 20 | Respondent info, setup, intro script, opening ethnography, tasks, wrap-up; 2–5 sessions |
    | A.3 User flow v2.0 | 5 | Test comments per stage, improvements marked with reasons |
    | B.1 Visual inspiration | 10 | Moodboard |
    | B.2 Style guide | 10 | Imagery, typography, colors, UI element styles, icons |
    | B.3 UI pattern library | 10 | Buttons, navigation, other components |
    | B.4 Hi-fi mockups and prototype | 40 | 4–5+ screens (390×844 or 360×800) from the style guide, based on flow v2.0, `figma.com/proto` link |

=== "4 · Case Study"

    | Part | Must include |
    |---|---|
    | A. Figma project file | All work in one file: online link and offline `.fig` |
    | B. Case study presentation | Project overview, problem statement, user research, ideation and wireframes, visual design and results, prototype link + QR, key learnings, about section |
    | C. Live presentation | All sections above, then share the screen and test the user flow in the Figma prototype |

    For core courses, complete one whole user flow; don't show only 4–5 screens.
