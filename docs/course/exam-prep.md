# Exam preparation

## Suggested 25-minute run order

| Minutes | Part |
|---|---|
| 0–2 | Title, one-liner, problem, solution |
| 2–7 | Research: plan, methods, key findings with quotes |
| 7–11 | Synthesis: themes and HMW, ideation, prioritization |
| 11–14 | User flow, Crazy 8s, lo-fi wireframes |
| 14–17 | Usability testing: what broke and what changed (v1 → v2) |
| 17–19 | Moodboard, style guide, pattern library |
| 19–24 | Live hi-fi prototype demo of the full flow |
| 24–25 | Key learnings, about me, thanks |

Then open the Figma file and walk the sections left to right during the inspection.

## What strong case studies do

Two A-grade presentations from another group followed the same pattern:

1. **One story arc:** title → problem → solution → research → synthesis → sketches and flow → style guide → hi-fi screens → live demo → key learnings → about me.
2. **Real artifacts on screen:** affinity boards, prioritization matrices, paper sketches and comparison tables — not only polished slides.
3. **Every design decision traced to research:** "Users said X, so I built Y."
4. **One visual identity** across the whole deck.
5. **A smooth live demo** of one complete flow, rehearsed in advance.
6. **Short text on slides**, with the talking done over visuals.

Neither showed usability test results and the resulting changes. Adding a "what testing changed" slide covers a graded rubric item and a likely question.

## Theory to review

- Design thinking, double diamond, Lean UX
- Interviews vs surveys; qualitative vs quantitative; recruiting and bias
- The design sprint
- Affinity mapping, HMW, feature prioritization
- Visual hierarchy, Gestalt, Fitts's, Hick's and Jakob's laws, affordance
- Color, contrast (WCAG), typography scale, grids and spacing
- Lo-fi vs hi-fi; components, variants, auto layout
- Usability testing: moderated vs unmoderated, task design, think-aloud, why five users
- Success metrics and iteration
- Design handoff, atomic design
- Portfolio case study structure

For each topic, be ready to answer *"How did you apply this in CampusSwap?"* The [glossary](../concepts/ux-glossary.md) links each term to the project.
